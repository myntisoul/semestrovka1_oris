## Запуск проекта через Docker

### Требования

Для запуска проекта необходим Docker Desktop с поддержкой Docker Compose.

### Инструкция по запуску

1. Склонировать репозиторий или скачать его в виде ZIP-архива.
2. Открыть терминал в корневой папке проекта, где находится `docker-compose.yml`.
3. Создать файл `.env` на основе `.env.example` и указать необходимые переменные окружения.
4. Выполнить команду:

   ```powershell
   docker compose up --build -d
   ```

5. После запуска контейнеров открыть сайт по адресу:

   http://127.0.0.1:8888

Docker Compose автоматически собирает приложение, запускает SQL Server, создаёт базу данных и заполняет её начальными данными.

### Остановка приложения

```powershell
docker compose down
```

### Просмотр логов

```powershell
docker compose logs -f
```

### Проверка состояния контейнеров

```powershell
docker compose ps -a
```

Данные базы хранятся в Docker volume и сохраняются между обычными перезапусками контейнеров.
