# Цитадели Wiki

## Запуск в Docker

Нужен запущенный Docker Desktop в режиме Linux-контейнеров или Docker Engine с Compose. Из корня проекта выполни:

```powershell
docker compose up --build -d
```

Compose запускает SQL Server, ждёт успешной проверки подключения, создаёт базу `OrisDb` и применяет схему. При первом запуске он заполняет базу начальными данными. Веб-приложение запускается после успешной инициализации.

Сайт открывается по адресу <http://127.0.0.1:8888/>. Если порт занят, задай другой, например `$env:ORIS_HTTP_PORT = '8890'`, и используй этот порт в браузере.

```powershell
docker compose ps -a
docker compose logs db-init app
docker compose down
```

Завершение `db-init` с кодом `0` означает, что база готова. `docker compose down` останавливает проект и сохраняет БД и загруженные картинки в именованных томах. При следующем запуске схема проверяется снова, а начальные записи не загружаются повторно.

Compose создаёт отдельный экземпляр SQL Server и не занимает порт `1433` на компьютере. Если у тебя уже есть база в отдельном контейнере, для переноса своих записей потребуется резервная копия и восстановление. Старый контейнер можно оставить запущенным.

Для локального запуска предусмотрен пароль SQL Server по умолчанию. Чтобы использовать свой, задай `MSSQL_SA_PASSWORD` в локальном файле `.env` **до первого запуска**. Изменение переменной не меняет пароль в существующем томе SQL Server.

## Тесты

```powershell
dotnet test tests/Semestrovka.Tests.csproj
```

Для интеграционного теста CRUD задай `ORIS_TEST_SQL` со строкой подключения к отдельной тестовой базе.
